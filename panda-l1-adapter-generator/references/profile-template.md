## 信息完整度

- 评级：`★☆☆☆☆` / `★★☆☆☆` / `★★★☆☆` / `★★★★☆` / `★★★★★`
- 理由：说明已识别的路由、参数、鉴权、业务码和前置数据覆盖情况；缺失项、未读文件和仅有推断的字段必须明确列出。
- 评级规则：
  - `★☆☆☆☆`：未发现可用接口证据，主要字段待确认。
  - `★★☆☆☆`：发现路由，但参数、响应或鉴权信息大面积缺失。
  - `★★★☆☆`：路由和主要参数可追溯，业务码或前置数据仍有缺口。
  - `★★★★☆`：主要七字段有代码/文档证据，仅少量边界项待确认。
  - `★★★★★`：七字段和关键约束均有充分证据，并已完成人工核对；仍需以实际测试验证为最终依据。
